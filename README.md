# 音乐解密工具 · Music Decryptor

本地优先（离线可用）的音乐解密工具：离线解密 **网易云 `.ncm`**、**QQ 音乐 QMC / MGG / MFLAC / 2026 新版 musicex**、
**酷我 `.kwm`** 等加密格式；遇到文件内没有密钥的格式，先用**你自己的账号**按需获取钥匙（`ekey`），
拿不到再**自动切换**到“备用搜索 → 下载安全音源”流程；解密结果可按**目标音质（MP3 / FLAC / WAV）自动转码**。
可打包为一个带自定义图标的独立 `MusicDecryptor.exe`（Windows 10+，免安装）。

> ⚠️ **仅限个人本地研究 / 个人备份**：只处理你本机已有的加密文件或你自己的备份。
> 自动获取 `ekey` 使用**你自己的登录态**（在设置里一次性填写、仅存本机），只调用平台官方
> `GetEVkey` 接口 —— **不绕过任何付费/授权**，也不做内存扫描、浏览器 cookie 抓取之类的“凭证窃取”。
> 本项目**不含任何音频内容**；请遵守当地法律与平台条款，勿传播版权内容。
>
> 完整设计见 [DESIGN.md](DESIGN.md)；备用音源改造记录见
> [docs/备用资源获取模块-改进方案.md](docs/备用资源获取模块-改进方案.md)。

当前版本：**1.0.20-dev5**

## 特性

- **离线优先**：NCM / QMCv1 / QMCv2（含 `QTag` 内嵌密钥）/ 酷我 KWM 等**完全离线**解密，无需联网、无付费 API。
- **新版 QQ 也能尽量离线**：2026 新版 `musicex`（尾部无密钥）用**你自己的登录态按需静默获取 `ekey`**
  （每曲一次、约 22 小时有效，过期自动重拉）；没有凭证或拉取失败时如实标记“需联网”并转备用搜索。
- **目标音质真正生效**：MP3（一律转）/ FLAC（无损升级）/ WAV（保持无损、有损降级），**解密与备用下载两条路径统一**。
- **自带转码引擎、零新增依赖**：复用 **PySide6 自带的 FFmpeg 库**（ctypes 动态加载，**不打包 `ffmpeg.exe`**）；
  引擎加载不到时**静默保留原格式**，其余功能不受影响。
- **备用下载**：8 条内置音源（本地 / 酷我 / 酷狗 / 咪咕 / 聚合(NetEase) / 维基共享 / 互联网档案馆 / 手动补链），
  顺序可配；**华语歌自动“咪咕优先、CC/PD 垫底且按需检索”**。
- **三道硬门槛 + 两道安全网**：歌名+歌手**同一读法**硬门槛 → **跨平台时长核验**（标注 + 实测互证）→
  真实文件头/码率校验 → **完整度门禁**（11 秒提示音、截断一律判废）；解密结果另过**音频头安全网**。
- **稳**：超时 + 重试，逐源切换，单文件失败不影响整批；SHA-256 去重 + 资源台账
  （失败源进负缓存：无结果 6 小时 / 出错 15 分钟内不重复白试）。
- **同事友好**：**拖入即自动开始**（可关）、一键「打开输出目录」、设置/窗口按屏幕自适应；
  `QQ 音乐凭证` 收进“管理员一次配置”折叠区，日常使用者无需理会。
- **零原生依赖**：AES/TEA 纯 Python（无 `pycryptodome`），网络层标准库（无 `requests`）；
  运行时仅需 PySide6（+ 可选 mutagen）。

## 支持格式

| 平台 | 扩展名 | 离线 |
|---|---|---|
| 网易云音乐 | `.ncm`（mp3 / flac 载荷 + 元数据/封面） | ✅ |
| QQ 音乐 QMCv1（静态加密） | `.bkcmp3 .bkcm4a .bkcflac .bkcwav .bkcape .bkcogg .bkcwma .tkm` 及十六进制命名 | ✅ |
| QQ 音乐 QMCv2（密钥族） | `.qmc0 .qmc2 .qmc3 .qmc4 .qmc6 .qmc8 .qmcflac .qmcogg` | ✅（内嵌密钥）|
| QQ 音乐 MGG / MFLAC（旧） | `.mgg .mgg0 .mgg1 .mggl .mflac .mflac0 .mmp4` —— `QTag` 内嵌密钥 | ✅ |
| QQ 音乐 2026 新版 **musicex** | `.mgg / .mflac / .mmp4`（尾部只有歌名信息、**无密钥**） | ✅ **配置登录态后自动取 `ekey`**；无凭证则转备用 |
| QQ 音乐旧版 `STag` | 同上扩展名 | ❌（文件内无密钥）→ 自动转备用 |
| 酷我音乐 | `.kwm / .kwd` | ✅（密钥内嵌）|
| 已是明文 | `.mp3 .flac .ogg .m4a .aac .wav .ape .wma .dff` | 直接复制 / 按目标音质转码 |

### 目标音质（自 v1.0.18）

| 源格式 | 目标 MP3 | 目标 FLAC | 目标 WAV |
|---|---|---|---|
| 有损（`.mgg`→OGG、M4A、WMA…） | → **MP3 320k** | **降级 MP3**（日志注明“未做无效升格”） | **降级 MP3** |
| 有损（本身就是 MP3） | 原样（零开销） | 同上 | 同上 |
| 无损（FLAC / WAV / APE / DFF） | → MP3 320k | → FLAC | **保持无损**（FLAC 不展开成 WAV） |

## 安装

需要 **Python 3.10+**（开发验证于 3.14）与 Windows 10/11。

```powershell
python -m pip install -r requirements.txt
```

运行时依赖只有 **PySide6**（界面）与**可选的 mutagen**（写标签/封面，缺失则跳过写标签）；
解密/转码/网络/去重全部使用标准库或仓库内的纯 Python 代码。
转码引擎复用 **PySide6 自带的 FFmpeg 库**（本机实测 6.12 版）：库文件名/结构体布局随版本变化也没关系——
运行时自动发现，缺库/缺编码器时自动降级（保留原格式），不影响解密主流程。

## 使用

**同事（日常，零学习成本）**：
1. 双击 `MusicDecryptor.exe`；
2. 把加密歌曲（或整个文件夹）**拖进窗口** —— 会**自动开始**，不用点任何按钮；
3. 表格里出现「已解密」即完成；点 **「打开输出目录」** 取文件。

**管理员（只做一次）**：`设置… → 点开「QQ 音乐凭证」→「从剪贴板粘贴 Cookie」→ 确定`
（先在浏览器登录 QQ 音乐网页版，F12 → 任一请求的 Cookie 里复制整条即可，软件会自动取出 QQ 号）。
之后同事无需再碰设置；`ekey` 约 22 小时过期，软件会在处理到新文件时**按需自动重拉**。
把凭证清空即可关闭该功能（行为回到“如实报需联网 → 转备用搜索”）。

```powershell
python main.py                     # 图形界面（拖拽 / 批量）
python main.py --cli "D:\in"       # 无界面批处理
python main.py --cli a.ncm --output D:\out --quality flac
python main.py --check-qt          # 自检：确认 Qt 能加载（界面起不来时先跑这个）
python main.py --check-ui          # 自检：主窗口与设置弹窗是否在本机屏幕上完整可见
python main.py --sources-report    # 打印生效的音源清单 + 台账健康统计
python main.py --selftest          # 运行自检
python main.py song.ncm --auto     # 启动后立即开始
```

**输出位置**：默认写到**源文件所在目录**（不落到 exe 自己的 `dist\`）；同名自动加序号，绝不覆盖源文件。
可在界面指定其它输出目录；窗口按屏幕工作区自适应，底部按钮不会被任务栏遮住。

## 疑难排查

- **双击 exe 弹出 `DLL load failed while importing QtCore: 找不到指定的程序`**：
  这是打包机 `PATH` 上存在 **同名但不同版本的 `icuuc.dll`**（例如 Poppler 自带的 ICU）被 PyInstaller 误打包，遮蔽了 Windows 系统 ICU 导致的。
  本仓库的 spec 已修复（过滤掉所有 `icu*.dll`）。若你自行改动打包配置，请保留该过滤；并用 `dist\MusicDecryptor.exe --check-qt` 回归。
- **界面起不来 / 无反应**：先跑 `python main.py --check-qt`；再用 `build\music_decryptor_console.spec` 构建控制台版，让报错直接打到命令行。
- **窗口或设置弹窗底部被屏幕/任务栏挡住**：先跑 `python main.py --check-ui`（或 `dist\MusicDecryptor.exe --check-ui`）。它会按你的屏幕工作区实测主窗口与对话框的几何并给出逐项结论；设置弹窗主体可滚动、`确定/取消` 已固定在底部。
- **某音源没结果**：平台接口会变（反爬/改版），只影响 `mmusic\search\` 下对应文件，可在设置里调整音源顺序或换用聚合网关。
- **新版 QQ 文件提示“需联网（需要账号 ekey）”**：这是 2026 新版 `musicex`（文件内确实没有密钥）。
  到 `设置 → QQ 音乐凭证` 一次性填入登录态即可自动获取；没有凭证时会照常转备用搜索，不会卡住。
  若提示“未登录/失效 → 请重新粘贴”，照做一次即可（通常数周才需要一次）。
- **提示“转码引擎不可用 / 转码失败，已保留原格式”**：这是**正常降级**——输出仍是可播放的原格式，
  只是没做格式转换（引擎复用 PySide6 自带的 FFmpeg 库，缺库的环境不做转码）。
- **Win10 自带播放器打不开解出来的 `.ogg`**：Windows 10 自带的「音乐/Groove」与 Windows Media Player
  **不内置 Ogg Vorbis 解码**，与文件无关（Win11 新版播放器 / PotPlayer / foobar2000 均正常）；
  `.mflac → .flac` 不受影响（Win10 原生支持 FLAC）。在 Win10 上要最通用，把「目标音质」设为 MP3。
- **重打包报“dist\MusicDecryptor.exe 正被占用”**：先关闭正在运行的软件（或等几秒让杀软扫描结束）再重跑 `build\build.ps1`。

## 备用音源

内置 8 条（顺序可在设置里调整）：
`本地曲库(离线) → 酷我 → 酷狗 → 咪咕 → 全网聚合(NetEase) → 维基共享(CC/PD) → 互联网档案馆(PD/CC)`，
外加**手动补链**（默认关闭；填了就优先使用，跳过歌名门槛但仍做全量校验）。

- **咪咕**：免登录 **PQ 128k**（实测下载字节数与官方声明一致）；HQ/SQ 需登录 → 自动降级，不绕过。
- **酷我 / 酷狗**：公开检索接口；酷我可退 FLAC→MP3，酷狗仅免费曲目给直链。
- **维基共享 / 互联网档案馆**：CC / 公有领域，专补冷门、古典、现场（几乎不含流行曲）。
- **华语歌自动排序（静默）**：文件名/元数据含汉字或命中常见华语歌手名单时，本次按
  「**咪咕优先 → 其余主流 → CC/PD 垫底，且仅主流全无候选时才检索**」执行；非华语歌保持你的配置顺序。
- 每个候选都要过：歌名+歌手同一读法硬门槛 → 跨平台时长核验 → 下载后完整度门禁；
  失败源进负缓存（无结果 6 小时 / 出错 15 分钟内不重复白试），全程有台账可查（`--sources-report`）。

平台改版只影响对应适配器（`mmusic/search/*.py`），解密核心与界面无需改动。

## 目录结构

```text
mmusic/            核心能力层
  crypto/          AES / TEA / NCM / QMC / musicex / KWM 解码
  search/          备用音源适配器 + 音源清单(pack) + 台账(index) + 页面嗅探(sniffer)
  pipeline.py      编排：解密 →（按目标音质转码）→ 备用下载 → 校验 → 写盘
  transcode.py     可选转码引擎（复用 PySide6 自带 FFmpeg 库）
  ekeys.py         新版 musicex 的 ekey 按需静默获取（用户自带登录态）
  downloader.py    下载结果校验 + 完整度门禁
ui/                PySide6 界面层（主窗口 / 设置 / 手动补链 / 几何自适应）
assets/            图标与生成脚本
build/             PyInstaller spec 与构建脚本
tests/             自检与合成夹具（含转码 / ekey / 界面自适应）
main.py            入口（GUI / --cli / --check-* / --selftest / --sources-report）
```
